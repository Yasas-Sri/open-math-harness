Filesystem access defines which files you can read or write. `sandbox_mode` is `workspace-write`: you hold tools that write. A file tool writes inside the paths its capability covers, and a write outside them is refused. A shell command starts in the workspace its call names, which is its working directory; what it may read and write is what the shell tool's own description states. Where that is the permissions of a Linux user, the workspace is where a command starts, not a limit: it can change whatever that user can, and nothing asks a person first.
